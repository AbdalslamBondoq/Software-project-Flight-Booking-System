# Prompt Records

This folder holds one Markdown record for each significant task we gave to an AI agent (§3.3 of the project instructions). Each record lists the version, goal, related requirements and diagrams, the key instructions we sent, the expected outputs, acceptance criteria, the agent used, and links to results.

The summary of every task is in [`docs/ai_development_log.md`](../docs/ai_development_log.md).
