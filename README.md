# Flight Booking System - Group  17 

Software Engineering course project (CS13477), developed with Agentic AI.

## Problem
Booking flights manually is slow and error-prone. This system lets customers search flights,
select seats, pay (simulated), and manage bookings, and lets admins manage flights.
