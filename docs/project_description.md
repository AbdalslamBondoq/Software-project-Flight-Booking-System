# Project Description - Flight Booking System 

## Overview
A web system that lets customers search for flights, book seats, pay (simulated),
and manage their bookings, and lets admins manage flights, airports, and aircraft.

## Stakeholders
- Customers (passengers)
- Airline admins

## Scope

### Customer
- Register and log in
- Search flights by origin, destination, and date
- Filter and sort results (price, time)
- View available seats and select one
- Create a booking
- Pay for the booking (simulated payment)
- Receive an e-ticket
- View their bookings
- Cancel a booking and receive a refund

### Admin
- Add, edit, and delete flights
- Manage airports and aircraft

### System
- Prevent two customers from booking the same seat
- Send a booking confirmation notification (simulated)

## Assumptions
- Payment and notifications are simulated.
- Refund policy: full refund if cancelled 48+ hours before departure, 50% otherwise.
