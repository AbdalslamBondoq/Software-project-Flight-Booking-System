# Project Description - Flight Booking System (Group 17)

## Goal
Build a web application that lets customers search for flights, reserve a seat, and manage
their bookings, while letting airline staff maintain flights, airports, and aircraft.

## Users
- **Customers** who want to find and book flights.
- **Airline admins** who maintain the flight data.

## Main Challenge
Keeping seat reservations consistent: a seat must never be booked by two customers at the same time.

## Boundaries
The system covers searching, booking, and managing flights. Payment and notifications are
simulated, not connected to real services.

The detailed list of what the system must do is in `requirements.md`, and the build order is in
`incremental_development_plan.md`.
